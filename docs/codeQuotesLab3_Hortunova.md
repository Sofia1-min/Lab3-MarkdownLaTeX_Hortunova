# Блоки кода и цитаты

## Блоки кода

**1. Команда Git в виде inline-кода:**

Команда `git status` показывает состояние репозитория.

**2. Блок кода на языке Python:**

```python
print("Hello, Markdown!")
```

**3. Блок кода без указания языка:**

```
string name;
name = Console.ReadLine();
Console.WriteLine(name);
```
