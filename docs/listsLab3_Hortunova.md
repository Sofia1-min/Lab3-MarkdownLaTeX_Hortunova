* 1
* 2
* 3

# Нумерованные списки

Создаются с помощью:

1. Первый пункт
2. Второй пункт
3. Третий пункт

# Вложенные списки

Просто используйте отступ (таб или 4 пробела):

1. Пункт
   * Подпункт
   * Подпункт

# Как создать репозиторий

## План разработки

## Шаг 1: Подготовка структуры

## Задачи на сегодня

1. Создать папку проекта со следующей структурой:
   * Файл README.md для описания проекта
   * Папка src/ для хранения исходного кода
   * Папка docs/ для документации
   * Файл .gitignore для исключения ненужных файлов

1. Изучить систему контроля версий
   * Git базовые команды
   * Работа с ветками
   * Устаревший подход Современный workflow

2. Освоить разметку документации
   * Markdown синтаксис
   * Форматирование текста
   * Создание таблиц и списков

3. Изучить основы программирования
   * JavaScript синтаксис
   * Работа с DOM
   * Асинхронные операции

## Шаг 2: Настройка репозитория

2. Инициализировать Git-репозиторий

```bash
git init
```

3. Настройка репозитория. Добавить все файлы в staging area

```bash
git add .
```

4. Проверить статус изменений

```bash
git status
```

5. Создать первый коммит с описанием

```bash
git commit -m "Initial commit: базовая структура проекта"
```

## Шаг 3: Работа с удалённым репозиторием

4. Настройка удаленного репозитория

```bash
git remote add origin <url>
git push -u origin main
```
